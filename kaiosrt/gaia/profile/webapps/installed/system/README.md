# system

## Prerequisites

* GNU Make
* Node.js 7
* [`yarn`][yarn]

[yarn]: https://yarnpkg.com/en/docs/install

## Usage

### Make Options

* `make`
* `make clean`
* `make distclean`
* `make watch`
* `make build`
* `make test`

### NPM scripts

* `npm run clean`
* `npm run distclean`
* `npm run dev`
* `npm run build`
* `npm test`
